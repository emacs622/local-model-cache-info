Privacy policy

This policy covers Local Model Cache, a desktop utility operated by the account owner for personal use. This informational website does not receive authorization codes, tokens, Drive files, or model requests.

Information accessed and its purpose

The utility reads the Google account email to check that the intended account authorized access. It reads storage capacity and relevant folder and file metadata, including names, sizes, and checksums, to find and verify model caches. It downloads required model files, creates cache directories, and uploads cache files as requested. Granted Google permissions may cover more files than the utility uses; its operations are limited to configured tasks and cache locations.

Credential storage and transfer

Refresh credentials and client configuration are encrypted on the user's Windows computer using current-user operating-system protection. Refresh credentials are not sent to Colab. Cloud preparation and download tasks receive short-lived access tokens over encrypted connections. Tokens are used in process memory or restricted memory-backed files and are removed during task cleanup. Google's revocation, expiration, and security rules still apply.

File storage and retention

Model caches are stored in the user's Google Drive and may be staged on cloud machines the user starts. Task status, file names, sizes, checksums, and operational records may be kept in local or cloud working folders for recovery and troubleshooting. Reclaiming a temporary cloud machine does not delete the Drive cache.

Sharing and limited use

The utility does not sell Google user data, use it for advertising, or use Drive data to train general-purpose AI models. Data is processed for the requested functions between the user's computer, their Google Drive, and their authorized cloud tasks. The utility does not publish Drive files to other users.

Local Model Cache's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google and website or source hosting providers handle their own service data under their respective policies.

Revocation, deletion, and questions

The account owner can revoke access in Google's third-party connections settings and remove the locally stored application credentials. Removing credentials does not automatically delete model caches; the owner can separately delete those files in Drive. This utility is not distributed as a public service. Its sole user and operator handles questions and changes through the local application's configuration and maintenance process.
