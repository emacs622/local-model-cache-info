A personal desktop utility

Local Model Cache

Local Model Cache connects a user's own Google Drive model cache to cloud computing tasks that the same user controls. This website describes the application. It has no sign-in form, file uploads, or hosted inference service.

What the application does

  • Authorizes Google Drive access on the user's computer, allowing authorization to be reused when temporary cloud machines are replaced.
  • Finds and verifies model files, and saves models from public sources to the user's own Drive.
  • Downloads the required files to user-controlled cloud tasks, with public download sources available as a fallback.

Data and permissions

The application accesses relevant Drive file information and model contents, creates cache folders, and uploads cache files. Refresh credentials stay on the user's Windows computer, protected by the operating system's current-user encryption. Cloud tasks receive only short-lived access credentials.

This is a personal utility, not an official Google product. It does not provide public file sharing or account management. Authorization remains subject to user revocation and Google's security and expiration rules.
